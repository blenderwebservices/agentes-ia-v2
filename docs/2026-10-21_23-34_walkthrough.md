## 1. Resumen de Cambios Realizados

A solicitud del usuario, se implementó un sistema integral de detección y visualización en tiempo real del estado de la clave de API de Google Gemini en toda la plataforma:

1. **Detección Automática de Estado:**
   - Si la API Key está configurada y responde satisfactoriamente (`HTTP 200 OK` en endpoint de modelos de Google Gemini), el sistema opera en **Modo Real**.
   - Si la API Key está ausente, vacía o es rechazada por Google (`HTTP 400/403`), el sistema activa automáticamente el **Modo Mockup (Simulación)** sin interrumpir la experiencia de usuario.

## 2. Componentes Implementados

### 2.1 Backend: Servicio de Verificación y Resolución de Modelos
- **Archivo:** [`app/Services/GeminiAgentService.php`](file:///Users/franciscogomezbarragan/agentes-ia/app/Services/GeminiAgentService.php)
- **Método `checkApiKeyStatus(bool $forceRefresh = false): array`**:
  - Consulta en vivo contra `https://generativelanguage.googleapis.com/v1beta/models?key={$apiKey}`.
  - Almacena en caché el resultado (3 minutos) para optimizar la latencia y no consumir cuota innecesaria.
  - Provee metadata detallada: `is_valid` (bool), `mode` (`real` vs `mockup`), `status_code`, `badge_label`, `badge_color`, `key_preview` (ej. `AQ.Ab8R...SniMQ`) y fecha/hora de verificación.
- **Resolución Inteligente de Modelos (`resolveModelName`)**:
  - Mapea dinámicamente alias de modelos a las versiones vigentes (`gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-flash-latest`, etc.).
